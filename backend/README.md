# GeoCadastre-3D — FastAPI Backend Foundation

FastAPI REST backend service for the **GeoCadastre-3D** 3D Land & Vertical Property Cadastre Platform.

---

## 1. Project Architecture

GeoCadastre-3D is an enterprise-grade 3D Land and Vertical Property Cadastre platform combining high-precision spatial engines with SQLAlchemy 2.x persistence, Alembic database migrations, and real-time Three.js visualization.

```
+------------------------------------+------------------------------------+
                                     | HTTP / JSON (REST API)
                                     v
+------------------------------------+------------------------------------+

                   |                 |                   |

+------------------+----+  +---------+---------+  +------+----------------+
```

## 2. Local Setup & Virtual Environment

### Prerequisites
- Python 3.10+ (Verified on Python 3.14.3)

### Setup Steps
```bash
# 1. Navigate to the backend directory
cd backend

# 2. Create a virtual environment
python -m venv venv

# 3. Activate the virtual environment
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Windows (CMD):
.\venv\Scripts\activate.bat
# Linux / macOS:
source venv/bin/activate

# 4. Install dependencies
pip install -r requirements.txt
```

## 3. Database Modes & Configuration

### SQLite (Default Development Mode)
- **Database URL**: `sqlite:///./geocadastre3d.db`
- Automatically selected when `DATABASE_URL` is unset or empty.
- Configured with `check_same_thread=False`, 30s timeout, and `pool_pre_ping=True`.

### PostgreSQL (Production Mode)
- Set the `DATABASE_URL` environment variable to a standard PostgreSQL DSN.
- Legacy `postgres://` prefixes are automatically normalized to `postgresql://` for SQLAlchemy 2.x.
- Configured with `pool_size=10`, `max_overflow=20`, `pool_recycle=1800`, and `pool_pre_ping=True`.

```bash
# Example PostgreSQL export (Linux / macOS):
export DATABASE_URL="postgresql://postgres:password@localhost:5432/geocadastre3d"

# Example PowerShell (Windows):
$env:DATABASE_URL="postgresql://postgres:password@localhost:5432/geocadastre3d"
```

### Environment Variables Template (`.env.example`)
Copy `.env.example` to `.env` for local customizations:
```ini
# Database Connection URL
DATABASE_URL=sqlite:///./geocadastre3d.db

# Server Bindings
HOST=127.0.0.1
PORT=8000
ENVIRONMENT=development
LOG_LEVEL=info

# CORS Whitelist (use * for local dev or comma-separated origins for production)
CORS_ORIGINS=*
```

> [!WARNING]
> **SAFETY & SECRETS**: NEVER commit real database passwords, production credentials, API keys, or private certificates into version control. Keep `.env` git-ignored.

## 4. Database Migrations (Alembic) & Initialization

```bash
# Check available migration heads
alembic heads

# Check current applied migration in the active database
alembic current

# Apply migrations up to head (creates schema)
alembic upgrade head

# Generate a new autogenerated migration revision
alembic revision --autogenerate -m "Schema changes"
```

### Database Initialization & Idempotent Seeding
```bash
# Initialize ORM tables directly (non-destructive)
python init_db.py

# Seed initial prototype dataset (1 parcel, 5 properties, 1 LiDAR survey, 1 conflict, 6 topology evaluations)
python seed_db.py
```
*Note: `seed_db.py` is 100% idempotent and can be safely executed multiple times without generating duplicate records.*

## 5. Running the Backend Server


## 7. API Endpoints Reference

### General & Health
| Endpoint | Method | Description |
| :--- | :---: | :--- |
| `http://127.0.0.1:8000/` | `GET` | Root Project Information & Status |
| `http://127.0.0.1:8000/api/health` | `GET` | Service Health Check |
| `http://127.0.0.1:8000/api/health/db` | `GET` | Database Persistence Health Probe (`SELECT 1`) |

### Cadastral Properties (3D ULPIN)
| Endpoint | Method | Description |
| :--- | :---: | :--- |
| `http://127.0.0.1:8000/api/properties` | `GET` | List all 3D cadastral property units |

| `http://127.0.0.1:8000/api/properties/ulpin/{ulpin}` | `GET` | Search property by 3D ULPIN string |

### Parcels & GIS
| Endpoint | Method | Description |
| :--- | :---: | :--- |
| `http://127.0.0.1:8000/api/parcels` | `GET` | List all base 2D cadastral parcels |
